# Project memory

Read CURRENT_STATE first, then relevant ARCHITECTURE, DECISIONS and KNOWN_ISSUES.
Update after verified slices, before handoffs, and before final reporting.
Store concise facts and reproducible commands, never credentials/private source.

- CURRENT_STATE: phase, active task, last verified commit, features, next three steps.
- DECISIONS: dated decisions, alternatives and reasons.
- ARCHITECTURE: ownership, contracts, dependency flow.
- KNOWN_ISSUES: severity, reproduction, workaround, next owner/action.
- TESTING: environment and precise passing/failing/skipped evidence.
- PHASE_LOG: milestone evidence and commits.
